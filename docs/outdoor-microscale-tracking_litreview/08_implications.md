## 1. 이미 한 선택들은 문헌이 지지한다

| 우리 결정 | 문헌 근거 |
|---|---|
| 정확도 적응형 지오펜스 (부정확하면 자동전환 포기 → 수동 버튼) | 소형 지오펜스 오탐 **40.2%** (Wray 2019, [10.1111/acer.13991](https://doi.org/10.1111/acer.13991)). 저자도 "정밀도 개선 전까지 신중히 쓰라"고 결론 |
| **accuracy 값으로 걸러내기** (±12m 게이트, 적응 반경) | 보고 accuracy 와 실제 오차가 **지수 관계**이고, 임계 필터링이 큰 오차를 실제로 줄임 (Farine 2024, [10.1111/2041-210X.14433](https://doi.org/10.1111/2041-210X.14433)) |
| 진입/이탈 반경 분리(히스테리시스) + 3초 dwell | Hecht 박물관이 **진입 임계 A / 이탈 임계 B (A>B) + 슬라이딩 윈도우**를 같은 목적으로 사용 (Lanir 2014, [10.1111/cgf.12382](https://doi.org/10.1111/cgf.12382)) |
| 나침반 대신 GPS 진행방향 | 자력계 국소 간섭 취약 + 경로망이 방향을 대체 가능 (Alaoui 2017, [10.1155/2017/7951346](https://doi.org/10.1155/2017/7951346)) |
| 레이더(방향+거리) UI | 정밀 측위 전제 안내는 야외 문화시설에서 한계에 부딪힘 (Othman 2018, [10.1155/2018/5740520](https://doi.org/10.1155/2018/5740520)) |
| 관별 좌표를 현장 반복 측정으로 확정 | 오차의 상당 부분이 **반복 측정 간 변동**에서 옴 (Osborne 2025, [10.1002/2688-8319.70015](https://doi.org/10.1002/2688-8319.70015)) |

**단, 게이트에는 문헌이 준 경고가 있다.** Farine et al. 은 임계를 조일수록 **표본이 사라지는**
트레이드오프를 명시한다. 우리가 ±12m 에서 락 실패를 자주 겪은 것이 정확히 그 현상이다.
기준을 낮출 게 아니라 **환경(하늘 시야)을 바꿔 측정**하는 게 맞는 대응이다.

## 2. 1순위 — 산책로 경로망 스냅 (근거가 크게 강해졌다)

Alaoui et al. (2017)이 **넓은 개방 공간**에서 라우팅 그래프로 얻은 결과:

- 비보조 PDR 드리프트 **8% → 거의 0**
- **평균 오차 3–5m**
- 그래프가 자이로 드리프트 보정 · 보폭 교정 · **기기 지향과 보행방향 어긋남 추정**을 동시 수행

우리 부지는 그 논문의 대상(공항·쇼핑몰급 개방공간)보다 **경로가 단순하고 개수가 적다.**
관람객이 정해진 산책로로 다니므로 제약이 잘 먹는 조건이다.

**설계 지침 (Berjisian 2022 의 실패 모드를 반영)**
- ⚠ **평행 시설 주의**: 같은 방향으로 나란한 두 길이 있으면 오매칭이 잦다 → 산책로 폴리라인을
  너무 촘촘히 넣지 말고 **주요 동선만** 넣는다
- ⚠ **누락 링크 주의**: 관람객이 실제로 다니는데 데이터에 없는 길이 있으면 엉뚱한 곳으로 스냅된다
  → 잔디 횡단 등 비공식 동선이 많으면 **스냅 강도를 낮추거나 적용 구역을 한정**
- ⚠ **역방향 통행 허용**: 산책로는 일방통행이 아니므로 방향 제약을 걸지 않는다
- ⚠ 문헌 성능(70–90%)은 **외부 검증 시 더 낮아진다**. 낙관적 기대를 걸지 말 것
- 스냅 결과가 원 위치에서 **일정 거리 이상 벗어나면 스냅을 포기**(신뢰 하한)

## 3. 2순위 — 진행방향 기반 인접 관 판별

마주보는 두 문(180° 차이)은 자체 계산상 20m 접근 시 99.6% 구분된다.
경로망을 넣으면 **방향 추정 자체가 더 안정**되므로(Alaoui 2017), 1순위와 결합할 때 더 좋아진다.

## 4. 새로 발견한 즉시 적용 가능한 기법

**(a) 기기 자세로 GPS 신뢰도 가중** — Farnham (2015, [10.1049/iet-net.2015.0007](https://doi.org/10.1049/iet-net.2015.0007))
관광시설 실증에서 **가속도계로 기기가 평평/수직인지 판별해 raw GPS 를 필터링**하니 정밀도가 개선됐다.
관람객이 폰을 보고 있을 때(안정된 자세)의 값을 더 신뢰하고, 주머니·흔들림 상태의 값은 낮게 가중한다.
브라우저 `DeviceMotionEvent` 로 구현 가능하며 **경로망보다 훨씬 싸다.**

**(b) 환경 맥락 탐지** — Gao & Groves (2018, [10.1002/navi.221](https://doi.org/10.1002/navi.221))
GNSS 관측값만으로 개활지/중간/실내를 분류한다. 우리는 원시 관측치가 없어 그대로 못 쓰지만,
**accuracy 시계열의 급변**을 같은 목적(터널·실내 진입 감지)에 쓰는 근거는 된다.
Zhao et al. (2018)의 "가짜 이동" 필터링도 같은 계열이다.

## 5. 기대치 — 문헌이 말해주는 현실

- **개활지 스마트폰 GNSS 중앙값 0.9–3.4m**, 중간 환경 ~30m. 우리 ±8~11m 는 **환경 등급의 문제**지
  구현 실패가 아니다.
- **경로망을 넣으면 3–5m 가 현실적 목표**다(Alaoui 2017). 1m 는 인프라 없이 불가.
- **소형 지오펜스는 문헌상 40% 오탐**. 우리가 겪은 어려움은 정상이다.

## 7. 미완 — 본문 확인이 남은 최우선 2편

3라운드(alphaXiv)에서 **우리 두 축을 정면으로 다루는 문헌**을 찾았으나 커넥터가 끊겨 본문을 못 읽었다.
재연결 시 **이 둘부터** 확인한다.

| 문헌 | 우리 어느 결정에 걸리나 |
|---|---|
| *Evaluating Smartphone GNSS Accuracy for **Geofenced** Operations* ([arXiv:2603.26706](https://www.alphaxiv.org/abs/2603.26706)) | 지오펜스 반경·정확도 기준. 규제(6GHz) 맥락이라 **정확도 요건을 엄격히 정량화**했을 가능성 → 우리 ±12m 게이트와 28m 반경의 타당성을 직접 대조할 수 있다 |
| *Reliable **Heading Tracking** for Pedestrian … Using Commodity Devices* ([arXiv:2410.06400](https://www.alphaxiv.org/abs/2410.06400)) | **진행방향 기반 인접 관 판별(2순위)** 의 직접 선행연구. 초록이 "기존 관성융합·ML 접근의 한계"를 지적하므로, 우리가 GPS course 를 쓰기로 한 선택의 타당성 검증에 쓸 수 있다 |

## 남은 공백 — 우리가 직접 메워야 할 부분

문헌에서 **과학관 산책로 규모(수백 m, 개활지+반차폐 혼재)에 경로망 제약을 적용한 사례를
찾지 못했다.** Alaoui 는 공항·쇼핑몰, Berjisian 은 도시 교통망이다.
따라서 우리 적용은 **선행연구의 직접 이식이 아니라 규모 이전(transfer)** 이며,
Berjisian 이 경고한 "전이성 부족"이 그대로 적용된다. **현장 검증을 반드시 거쳐야 한다.**
