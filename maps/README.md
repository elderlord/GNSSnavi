# 실내 약도 이미지

건물별 정적 약도를 `hall-01.png`, `hall-02.png` … 형태로 넣고
`index.html`의 각 `VENUES[].mapImage`에 경로를 지정하세요.

- 실내 진입(지오펜스) 시 위치 추적을 중단하고 이 이미지를 전체화면으로 표시합니다.
- 미지정(`mapImage:null`) 시에는 "약도 준비 중" 플레이스홀더가 나옵니다.
- 배경 약도(레이더 밑)를 쓰려면 대각 기준점 2개의 실좌표+픽셀좌표를
  `index.html`의 `SITE_MAP`에 기록해야 위경도↔픽셀 변환이 됩니다. (인수인계서 §7)
